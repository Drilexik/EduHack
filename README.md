# EduHack Bypass

Obchází detekci přepnutí okna, ztráty fokusu a kopírování na webu.

## 🚀 Instalace (Chrome / Edge / Brave)

1. Stáhni tento repozitář jako **ZIP** a rozbal ho.
2. V prohlížeči otevři adresu `chrome://extensions/`.
3. V pravém horním rohu zapni **Režim vývojáře** (Developer mode).
4. Klikni na **Načíst rozbalené** (Load unpacked) a vyber rozbalenou složku.

Hotovo. Rozšíření běží automaticky.
