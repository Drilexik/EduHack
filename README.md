# EduHack Bypass

Obchází detekci Copy/Paste, UnFocus pomocí DOM Js na všech webech.

## 🚀 Instalace (Chrome / Edge / Brave)

1. Stáhni tento repozitář jako **ZIP** a rozbal ho.
2. V prohlížeči otevři adresu `chrome://extensions/` případně `edge://extensions/` nebo `brave://extensions/` .
3. V pravém horním rohu zapni **Režim vývojáře** (Developer mode).
4. Klikni na **Načíst rozbalené** (Load unpacked) a vyber rozbalenou složku.

Hotovo. Rozšíření běží automaticky.

Lze otestovat že vše funguje pomocí HTML stránek `detector.html` a `flash_detector_fixed.html`
